# Changelog

Versions follow `MAJOR.MINOR.PATCH`; a `vX.Y.Z` tag starts a release. The section for the tagged version goes into the GitHub Release and the Sparkle update window, so list items are written on a single line.

## 1.1.12 - 2026-09-12

### Added
- Weather for any city: search for your city in settings instead of picking from a fixed list, or press My Location to use where your Mac is.

### Changed
- Automatic day and night mode follows sunrise and sunset for the place you choose.
- The installer no longer asks for Rosetta on Apple Silicon Macs.
